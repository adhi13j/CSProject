Propositional-logic parse trees

Part A stores a formula as a binary parse tree and runs the course algorithms on it (infix → prefix → tree, traversals, height, evaluation, truth tables) in C++17. Part B proves sequents in Lean 4. This report documents the algorithms, the measurements and what they show.

./logic_a1 --formula "((p+(~q))>r)" --table
./logic_a1 --formula "(p>q>r)" --task 3
./logic_a1 --cnf data/ca002.shuffled.cnf --shape balanced --task 4

Connectives: ~ not, * and, + or, > implies. Precedence ~ > * > + > >; > is right-associative, so p>q>r means p>(q>r).
