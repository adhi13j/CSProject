Results

Three data families: random formulas and left-deep chains of 10 … 1,000,000 nodes, the nine golden formulas, and eight SAT 2002 benchmark files built in two shapes. All rows are in bench/results.csv (columns dataset, shape, nodes, height, atoms, function, median_ms, aux_peak, rss_kb, status). Recursive functions always run in a fork()ed child, so a stack overflow is recorded as CRASH instead of ending the run.
